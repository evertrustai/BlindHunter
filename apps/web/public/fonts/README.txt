Brand wordmark font
===================

The BlindHunter logo ("BLINDHUNTER") is set in "Rubik Glitch", loaded via
@font-face in apps/web/src/styles/global.css (family "Rubik Glitch", used
through the --font-logo token in tokens.css).

RubikGlitch.ttf is committed here so the branded logo renders on every clone.
It is licensed under the SIL Open Font License (see RubikGlitch-OFL.txt) — free
to use, embed, and redistribute, so it is safe for a public repository.

If the file is missing, the logo falls back to IBM Plex Sans (still with the
red "B" and "H").
